# AAC Light-heavyweight: M1

##### Black Cat

- Watch glowing claws for sequential half-room cleave
- BLACK CAT CROSSING - Cone AoEs in the order purple lines appear
- MOUSER - Telegraphed grids get hit in the order they appear
  - Any grid hit TWICE will break that square and you die
  - Abuse 4 inner squares - they'll never all be gone
- ELEVATE AND EVISCERATE - Aim arrow at an undamaged square if you are targetted
- LEAPING - Changes the START point of all BLACK CAT CROSSING and MOUSER attacks to the tethered marker
